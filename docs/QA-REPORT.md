## Форма «Задати питання» (`/forum`)

Поля: `name*`, `email*`, `message*` (усі required) + приховане `company` — honeypot проти спаму ✓
Кнопки: «×», «Відправити», «Відміна».

**Перевірка порожнього надсилання (без реальної відправки):**
- Блокується нативно, повідомлення: `name/email/message: Please fill out this field.`
- URL не змінюється, дані нікуди не йдуть ✓
- **Зауваження (низький пріоритет):** повідомлення валідації — англійською, бо береться з локалі браузера.
  Для українського користувача з uk-локаллю воно буде українським автоматично; якщо хочете гарантовану
  українську — треба власні тексти `setCustomValidity` або HTML-підказки під полем.

## Виявлені зауваження (не дефекти, а борг)

1. **Лічильник фільтра не оновлюється.** Після надсилання вкладка показує «Інше (1)», хоча питань у
   темі «Інше» вже два (Марія + тестове). Схоже, лічильник рахує лише **опубліковані з відповіддю**
   записи — тоді це не баг, але варто перевірити, чи так задумано. Якщо так — краще перейменувати
   вкладку на «Інше · 1 відповідь», щоб цифра не читалась як кількість питань.
2. **Не перевірено: поведінка при порожньому форумі** (0 питань) — зараз на сторінці є 1 запис.
3. Дубльований H2 «Напишіть мені» ×3 на головній — впливає на семантику й SEO (див. SEO-AUDIT.md, п.6).
4. Модальне вікно форми: закриття по Esc і фокус-пастку окремо не тестував.
5. Порожнє надсилання блокується, повідомлення англійською (`Please fill out this field`) — береться з
   локалі браузера; для uk-локалі буде українською автоматично. Гарантована українська = власні тексти
   через `setCustomValidity`.
